## Portfolio Rules

1. Never delete portfolio sections.
2. Never permanently remove portfolio cards.
3. Never replace Michael Perez hero image.
4. Never modify branding without approval.
5. Never change logo without approval.
6. Never remove modal functionality.
7. Portfolio sections may only be hidden temporarily, never deleted.
8. Any disabled section must be clearly marked with comments.
9. Before modifying portfolio cards, create backup.
10. Verify desktop, tablet and mobile responsiveness before commit.
11. Preserve all image paths unless explicitly requested.
12. Never perform large refactors without approval.
13. Always use minimal safe changes.
14. Keep restoration path simple for future reactivation.

## Safety Rules

* Never delete existing sections without explicit approval.
* Always create backup before editing UI sections.
* Preserve all assets, logos and branding.
* Preserve Michael Perez hero image.
* Preserve responsive behavior.
* Use CSS hiding before code removal.
* Comment all temporary changes.
* Explain planned changes before editing.
* Make the smallest possible modification.
* Verify mobile, tablet and desktop after every UI change.
* Preserve Git history with descriptive commits.
